# Warehouse Inventory App

A React app for managing inventory, backed by Supabase (Postgres + Auth).

## Run locally
```
npm install
npm run dev
```
Then open the URL it prints (usually http://localhost:5173).

## Deploy for free (recommended: Vercel)
1. Push this folder to a new GitHub repository.
2. Go to vercel.com, sign up free with your GitHub account.
3. Click "Add New Project", pick this repo, and click Deploy.
   Vercel auto-detects Vite and builds it correctly — no config needed.
4. You'll get a free URL like `your-app.vercel.app` you can log into from any PC or phone.

## Deploy for free (alternative: Netlify)
1. Push this folder to GitHub.
2. Go to netlify.com, sign up free, "Add new site" -> "Import an existing project".
3. Build command: `npm run build`, publish directory: `dist`.
